# First Moon · 初月

Website for First Moon (firstmooncare.com), served by GitHub Pages from the `main` branch.

- `index.html`: the homepage (English and Traditional Chinese). `privacy.html`: the privacy notice.
- `assets/site.css` and `assets/site.js`: shared styles and the language switch.
- Survey link, waitlist link and contact email are set in the `CONFIG` object at the top of `assets/site.js`.
- `logo/`: logo and favicon images.
- `CNAME`: the custom domain for GitHub Pages.
