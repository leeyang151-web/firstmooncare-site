# First Moon · 初月

Website for First Moon (firstmooncare.com), served by GitHub Pages from the `main` branch.

- `index.html`: the whole site (English and Traditional Chinese).
- Survey link, waitlist link and contact email are set in the `CONFIG` object near the bottom of `index.html`.
- `logo/`: logo and favicon images.
- `CNAME`: the custom domain for GitHub Pages.
